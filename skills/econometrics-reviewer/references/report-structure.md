# Referee Report Structure

Use this order:

1. **Review scope and boundary**
2. **Paper summary**: question, estimand, design, main claimed contribution
3. **Overall assessment**: strengths, central risk, confidence limits
4. **Major concerns**
5. **Minor comments**
6. **Claim calibration and alternative interpretations**
7. **Reproducibility and transparency**
8. **Prioritized revision path**

For every major concern include:

```text
Concern ID: M1
Blocking: Yes/No
Manuscript pointer:
Evidence:
Concern:
Why it affects the paper's claim:
Resolution test:
```

Keep confidential-editor commentary out of the author-facing report unless the user explicitly requests a separate editor note. Never issue an accept/reject decision as though acting for a journal.
