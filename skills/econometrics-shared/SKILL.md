# Econometrics Shared

Treat this package as a reference library, not a standalone end-user workflow.

## Load references selectively

- Read [references/research-contract.md](references/research-contract.md) before analyzing an empirical design.
- Read [references/claim-strength.md](references/claim-strength.md) when calibrating causal or mechanism language.
- Read [references/inference-principles.md](references/inference-principles.md) when assessing standard errors, uncertainty, power, or multiple testing.
- Read [references/replication-standard.md](references/replication-standard.md) when auditing or preparing a replication package.

Apply user-supplied protocols and target-journal rules before these general defaults. Verify current journal policies against official sources when exact compliance matters.
